## 📌 Overview
Nexus is a centralized, digital Campus Resource Management and Issue Reporting System initially developed to streamline facility operations at the College of Engineering, Trikaripur. It replaces fragmented, manual administrative workflows with a transparent, data-driven digital ecosystem.

By digitizing issue reporting, Nexus allows students and faculty to log, track, and manage campus resource requests in real-time, significantly reducing administrative overhead and improving maintenance response times.

## ✨ Key Features
* **Centralized Issue Tracking:** Submit, view, and track the status of campus facility complaints in real-time.
* **Role-Based Access Control (RBAC):** Secure, distinct interfaces and permission levels for Students, Faculty, and System Administrators.
* **Dynamic Resource Allocation:** Automated workflows to assign resources and maintenance tasks efficiently.
* **Responsive Dashboard:** A clean, intuitive user interface accessible across desktop and mobile devices.

## 🛠️ Tech Stack
* **Frontend:** React, HTML5, CSS3
* **Backend:** Python, Flask
* **Database:** MySQL
